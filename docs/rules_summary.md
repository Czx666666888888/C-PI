# 2027 智能搬运比赛关键规则

依据用户上传的智能+工程创新赛道规则；以官方后续版本为准。

- 必须完全自主运行，完成定位、移动、避障、读取二维码、物料识别、抓取搬运和任务统计。
- 初始尺寸投影不大于 300×300 mm，高度不超过 400 mm；机械臂可出发后展开。
- 单个内置电源，比赛及调试中不得更换。
- 顶部需要明亮的任务码显示，字符高度至少 12 mm。
- 场地 2400×2400 mm；离开蓝色启停区后只能在灰色车道行驶；中心十字路宽 400 mm。
- 初赛二维码板 A4 横放，码为 80×80 mm；位置存在随机性。
- 任务码示例：156+123+516+231；颜色编号红1、黄2、蓝3、绿4、黑5、浅蓝6。
- 原料区旋转盘直径 300 mm，6–10 秒/圈。
- 两批物料按顺序抓取、粗加工区放置、暂存区放置并完成码垛，最后返回启停区。
- 跨区域行驶不能始终用夹爪夹住物料，必须放在机器人上。
- 运行中不能遥控。

此文档为开发摘要，不取代原规则。
